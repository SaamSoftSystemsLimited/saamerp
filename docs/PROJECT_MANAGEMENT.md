# GitHub project management

Owner: SaamSoftSystemsLimited. Repository: saamerp (private). Project title: SaamERP Delivery Roadmap (private).

Only sundayayandele is to be assigned initially. Do not add collaborators or change organization-wide defaults. Organization owners may retain inherent access; report effective access rather than promising exclusivity.

## Fields

- Status: Backlog, Ready, In progress, In review, Blocked, Done.
- Priority: P0, P1, P2.
- Module: domain label; Release: milestone.
- Start date, Target date, Estimate (hours).
- Requirement ID, Dependencies and Acceptance evidence in issue body.
- Risk: High/Medium/Low; Client coverage: Web/Android/iPhone in acceptance checklist.

## Views

Board grouped by status; Roadmap using Start date/Target date; table for backlog/estimates; filtered first-week view. Views and layout may require GitHub UI configuration if the API does not support them.

## Rules

WIP limit: one implementation task at a time. Epics group scope and remain open until children are accepted. Later phase dates are planning windows, not per-feature commitments. Mark Done only when acceptance evidence exists; merge alone does not imply specialist acceptance.

Weekly reviews use accepted work, remaining estimates and dependency changes. Keep sensitive financial/employee material out of issues; use synthetic examples and controlled external review evidence.
